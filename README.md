
# TaskFlow

A sample task management tool for organizing activities, tracking progress, and managing daily tasks.

## About the Project

TaskFlow is a fictional task management application designed to help users organize their activities and monitor task completion.

The project demonstrates how a task management tool can support personal productivity by allowing users to create tasks, add descriptions, set due dates, and track their progress.

This documentation is part of a technical writing portfolio project. TaskFlow is a conceptual prototype and is not a functional software application.

## Project Status

TaskFlow is currently a conceptual documentation project.

The documentation describes the proposed features and workflows of a sample task management application. No functional software has been developed as part of this project.

The project demonstrates technical writing skills, including documentation structure, instructional writing, and user-focused content development.

## Features

TaskFlow is designed to support the following features:

- **Task creation:** Create tasks with descriptive titles.
- **Task descriptions:** Add details to explain what needs to be completed.
- **Due dates:** Assign deadlines to tasks.
- **Task tracking:** Monitor task completion status.
- **Task organization:** View tasks from a central dashboard.

These features describe the intended functionality of the TaskFlow prototype.

## Usage

The TaskFlow prototype is designed around a simple task management workflow.

### Creating a Task

1. Open the TaskFlow interface.
2. Navigate to the Tasks dashboard.
3. Select the New Task button.
4. Enter the task name and description.
5. Set a due date if required.
6. Select the Save Task button.

### Completing a Task

1. Open the Tasks dashboard.
2. Locate the task you want to complete.
3. Select the task's completion control.
4. Confirm that the task status changes to completed.

**Note:** These steps describe the intended workflow of the fictional TaskFlow interface. They have not been tested against a functional application.

## Example Workflow

A student wants to keep track of an upcoming anatomy assignment.

The student creates a task with the following details:

| Field | Value |
|---|---|
| Task Name | Complete Anatomy Assignment |
| Description | Review the upper limb anatomy lecture notes and answer the assigned questions. |
| Due Date | 10 November 2026 |
| Status | Incomplete |

After completing the assignment, the student marks the task as completed.

This example demonstrates how TaskFlow is intended to support task organization and progress tracking.
